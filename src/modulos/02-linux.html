02 · Linux para pentesters

Kali es Linux, y la mayoría de servidores que atacarás también. Aquí aprendes a moverte por la terminal con soltura.

1. La terminal

📘 DefiniciónLa terminal (o shell) es una ventana donde escribes órdenes de texto. Bash y Zsh son los intérpretes más comunes.
kali@kali:~/Desktop$ ls -la
# usuario@equipo:carpeta_actual$   ← $ = usuario normal,  # = root
🧠 AnalogíaEl ratón es señalar con el dedo en un restaurante; la terminal es hablar directamente con el cocinero. Más rápido y preciso, pero tienes que saber qué pedir.

4. Permisos (rwx) — clave para escalar privilegios

⚠️ Permisos especiales que buscarás como atacante SUID (-rwsr-xr-x, la “s”): el programa se ejecuta con permisos de su dueño (a menudo root), lo lance quien lo lance. Si un binario con SUID permite ejecutar comandos → root. Buscar: find / -perm -4000 -type f 2>/dev/null
Ficheros escribibles por todos: si un script que ejecuta root es escribible por ti, añádele tu comando.

5. Tuberías y redirecciones

$ cat /etc/passwd | grep bash          # | pasa la salida de uno al siguiente
$ nmap 10.0.2.4 > escaneo.txt          # > guarda en fichero (sobrescribe)
$ echo "nota" >> notas.txt             # >> añade al final
$ find / -name flag.txt 2>/dev/null    # 2> redirige errores (los tiramos a la “papelera”)
$ cat users.txt | sort | uniq | wc -l  # ordenar, quitar duplicados, contar
$ cut -d: -f1 /etc/passwd              # sólo la 1ª columna separada por ':'
$ awk -F: '$3>=1000 {print $1}' /etc/passwd   # usuarios “humanos”
🧠 AnalogíaLa tubería | es una cadena de montaje: cada comando hace una tarea y le pasa el resultado al siguiente.

6. Usuarios y grupos

# Formato de /etc/passwd
juan:x:1000:1000:Juan Pérez:/home/juan:/bin/bash
# usuario:contraseña(x=en shadow):UID:GID:descripción:home:shell
# UID 0 = root. Shell /usr/sbin/nologin = no puede entrar.

Grupos peligrosos si tu usuario pertenece a ellos: sudo, docker, lxd, disk, adm (lee logs). Los veremos en privesc.

8. Bash scripting mínimo

#!/bin/bash
# ping-sweep.sh — descubre equipos vivos en 10.0.2.0/24
for i in $(seq 1 254); do
  (ping -c 1 -W 1 10.0.2.$i | grep "ttl=" | cut -d" " -f4 | tr -d ":") &
done; wait
💡 Útil cuando no hay NmapDesde una máquina comprometida (pivote) no tendrás Nmap. Este bucle te permite descubrir equipos de la red interna.
🔴 Nivel OSCP: estabilizar una shellCuando consigues una reverse shell “tonta” (sin autocompletar, Ctrl+C la mata), conviértela en una TTY completa: 
python3 -c 'import pty;pty.spawn("/bin/bash")'
# pulsa Ctrl+Z
stty raw -echo; fg
# pulsa Enter
export TERM=xterm; stty rows 40 columns 160
