07 · Enumeración de servicios

Ya sabes qué puertos hay abiertos. Ahora exprimes cada servicio para encontrar la vía de entrada: usuarios, versiones, ficheros compartidos, logins por defecto…

💡 La mentalidadPor cada puerto abierto pregúntate: ¿puedo entrar sin credenciales? ¿hay una versión vulnerable? ¿hay información (usuarios, ficheros) que me ayude en otro servicio?

21 · FTP

$ nmap -p21 -sC -sV 10.0.2.4
$ ftp 10.0.2.4            # prueba usuario: anonymous  contraseña: (vacía)
# Dentro del FTP:
ftp> ls          ftp> get fichero.txt       ftp> put shell.php     ftp> binary
⚠️ Qué buscarLogin anónimo, ficheros con credenciales, posibilidad de subir ficheros (si el FTP apunta a la carpeta web, sube una webshell). Versión vulnerable (vsftpd 2.3.4 tiene backdoor).

22 · SSH

$ nmap -p22 -sV 10.0.2.4
$ ssh usuario@10.0.2.4
# Enumerar usuarios válidos / versión. Si tienes credenciales o una clave id_rsa:
$ ssh -i id_rsa usuario@10.0.2.4

SSH casi nunca es la vía de entrada directa salvo fuerza bruta con credenciales débiles (módulo 10) o una clave privada encontrada en otro servicio.

139/445 · SMB (el más rentable)

$ enum4linux -a 10.0.2.4                       # todo-en-uno: usuarios, shares, grupos
$ smbclient -L //10.0.2.4/ -N                  # listar shares sin login
$ smbclient //10.0.2.4/tmp -N                  # conectar a un share
$ smbmap -H 10.0.2.4                            # shares y permisos (R/W)
$ crackmapexec smb 10.0.2.4 --shares -u '' -p ''
$ nmap -p445 --script smb-vuln-ms17-010 10.0.2.5   # EternalBlue
💡 Oro en SMBShares accesibles sin contraseña, ficheros de configuración, listas de usuarios (para fuerza bruta en otros servicios) y vulnerabilidades como MS17-010.

80/443 · HTTP (su propio módulo: el 08)

$ whatweb http://10.0.2.4         # tecnologías
$ nikto -h http://10.0.2.4        # escáner de vulns web rápido
$ gobuster dir -u http://10.0.2.4 -w /usr/share/wordlists/dirb/common.txt
$ curl -s http://10.0.2.4/robots.txt

25 · SMTP

$ nmap -p25 --script smtp-commands,smtp-enum-users 10.0.2.4
# Enumerar usuarios válidos con VRFY (manual con netcat):
$ nc 10.0.2.4 25
VRFY root        # 252 = existe, 550 = no existe

53 · DNS

$ dig AXFR dominio.local @10.0.2.4     # transferencia de zona
$ nmap -p53 --script dns-* 10.0.2.4

161/udp · SNMP

$ snmpwalk -v2c -c public 10.0.2.4     # 'public' = comunidad por defecto
$ onesixtyone 10.0.2.4 public
# SNMP puede filtrar procesos, usuarios, software y hasta rutas internas

3306 · MySQL / 1433 · MSSQL

$ mysql -h 10.0.2.4 -u root -p         # prueba root sin contraseña
$ nmap -p3306 --script mysql-empty-password,mysql-info 10.0.2.4

3389 · RDP

$ nmap -p3389 --script rdp-* 10.0.2.5
$ xfreerdp /u:user /p:pass /v:10.0.2.5

📝 Evaluación del tema

🧪 Práctica

Sobre Metasploitable 2: ejecuta enum4linux -a 10.0.2.4, entra por FTP anónimo, lista los shares SMB y prueba mysql -h 10.0.2.4 -u root sin contraseña. Documenta cada hallazgo. Al menos uno te dará acceso.

Pistas

En Metasploitable el FTP (vsftpd 2.3.4) y varios servicios son vulnerables; el MySQL root suele tener contraseña vacía; enum4linux lista muchos usuarios. Guárdalos para el módulo 09 y 10.
