Nivel 1 · eJPTv2

05 · Reconocimiento (OSINT / footprinting)

Recoger información antes de atacar. El reconocimiento pasivo no toca el objetivo (usas fuentes públicas); el activo sí lo toca (eso es el módulo 06).

1. ¿Qué buscamos?

  • Dominios y subdominios (mail.empresa.com, vpn.empresa.com…).
  • Rangos de IP que les pertenecen.
  • Correos y nombres de empleados (para adivinar usuarios y phishing).
  • Tecnologías que usan (servidor web, CMS, versiones).
  • Credenciales filtradas en brechas antiguas.

2. WHOIS y DNS

$ whois empresa.com          # dueño del dominio, fechas, servidores DNS
$ nslookup empresa.com       # IP del dominio
$ dig empresa.com ANY         # todos los registros
$ dig MX empresa.com          # servidores de correo
$ dig NS empresa.com          # servidores DNS
$ host -t txt empresa.com     # registros TXT (SPF revela proveedores)

Transferencia de zona (un clásico del eJPT)

📘 ¿Qué es?Si un servidor DNS está mal configurado, te entrega toda la lista de subdominios de golpe. Es oro.
$ dig AXFR empresa.com @ns1.empresa.com
# Si funciona, verás TODOS los registros: dev.empresa.com, internal.empresa.com...

3. Enumerar subdominios

$ sublist3r -d empresa.com
$ gobuster dns -d empresa.com -w /usr/share/wordlists/amass/subdomains-top1mil-5000.txt
$ dnsrecon -d empresa.com
# Fuentes web pasivas: crt.sh (certificados), VirusTotal, Shodan
$ curl -s "https://crt.sh/?q=%25.empresa.com&output=json" | jq -r '.[].name_value' | sort -u

4. Correos y empleados

$ theHarvester -d empresa.com -b all     # correos, subdominios, hosts
💡 De correo a usuarioSi los correos son nombre.apellido@empresa.com, probablemente el usuario de Windows sea nombre.apellido o napellido. Esto alimenta la fuerza bruta y el password spraying (módulo 10).

5. Google Dorks (hacking con buscadores)

DorkEncuentra
site:empresa.comTodo lo indexado del dominio
site:empresa.com filetype:pdfDocumentos (metadatos con nombres de usuario)
site:empresa.com inurl:adminPaneles de administración
intitle:"index of" site:empresa.comDirectorios abiertos
"password" filetype:logLogs con contraseñas
💡 Más recursos pasivosShodan (buscador de dispositivos conectados), Wayback Machine (versiones antiguas de webs), haveibeenpwned (brechas), Wappalyzer (tecnologías de una web), exiftool (metadatos de documentos descargados).

6. Fingerprinting de la web (en el límite pasivo/activo)

$ whatweb http://10.0.2.4         # tecnologías y versiones
$ curl -I http://10.0.2.4         # cabeceras (Server, X-Powered-By)
🔴 Nivel OSCPEn el examen OSCP el reconocimiento externo es limitado (te dan las IPs), pero el principio es el mismo dentro de la red: cada máquina comprometida es una nueva fase de recon. Documenta hostnames, dominios internos y usuarios que vayas descubriendo.
