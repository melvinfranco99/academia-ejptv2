01 · Redes para pentesters

Si no entiendes redes, no entiendes el hacking. Aquí aprenderás cómo viaja la información, qué es una IP, qué es un puerto y cómo calcular subredes (el eJPTv2 te pide identificar redes y hosts).

1. Dirección IP

📘 DefiniciónUna dirección IP (IPv4) identifica un equipo en una red. Son 4 números de 0 a 255 separados por puntos: 192.168.1.10. Son 32 bits.
🧠 Analogía: el edificioLa IP es la dirección postal. La red es la calle (192.168.1) y el host es el número de portal (.10). El puerto es el piso/puerta dentro del edificio.
Rango privado (RFC 1918)Dónde lo verás
10.0.0.0/8Empresas grandes, laboratorios (HTB usa 10.10.x.x)
172.16.0.0/12 (172.16–172.31)Empresas, Docker
192.168.0.0/16Casas, oficinas pequeñas, laboratorio eJPT
127.0.0.1localhost: el propio equipo

Las IPs privadas no salen a Internet directamente: el router hace NAT y las traduce a una IP pública.

2. Máscara de red y CIDR

📘 DefiniciónLa máscara dice qué parte de la IP es la red y cuál el host. En notación CIDR se escribe /24 = los primeros 24 bits son red.

/24255.255.255.0256254

💡 Truco rápidoHosts usables = 2(32 − CIDR) − 2. Se restan 2 porque la primera dirección es la de red y la última la de broadcast (mensaje para todos).
✍️ Ejemplo: 192.168.10.77/26
  1. /26 → quedan 6 bits de host → bloques de 2⁶ = 64.
  2. Los bloques en el último octeto son: 0, 64, 128, 192. 77 cae en el bloque 64–127.
  3. Red: 192.168.10.64 · Broadcast: 192.168.10.127 · Hosts: .65 a .126 (62 hosts).

💡 Esto explica NmapEl escaneo -sS (“SYN scan”) envía el SYN, si recibe SYN-ACK sabe que el puerto está abierto y corta con RST sin completar la conexión. Por eso se le llama “half-open” (medio abierto).



5. Modelo OSI y TCP/IP



💡 Regla mnemotécnica (de abajo a arriba)“Fue El Ratón Todo Su Pan Ayer” → Física, Enlace, Red, Transporte, Sesión, Presentación, Aplicación.


🧠 Analogía: enviar un paquete por mensajeríaEscribes una carta (aplicación), la metes en un sobre con número de departamento (puerto, transporte), le pones la dirección de la ciudad (IP, red), el repartidor de tu barrio la lleva al siguiente punto usando la matrícula del camión (MAC, enlace) por la carretera (física). Cada capa añade su “sobre” = encapsulación.



6. MAC, ARP, gateway y DNS


    

  • MAC: dirección física de la tarjeta de red (08:00:27:3a:1b:9c). Funciona solo dentro de la red local.
    • 

  • ARP: pregunta “¿quién tiene la IP 192.168.1.1? que me diga su MAC”. Herramienta: arp-scan -l o netdiscover para descubrir equipos en tu red.
    • 

  • Gateway (puerta de enlace): el router por el que sales a otras redes. Clave en pivoting.
    • 

  • DNS: traduce nombres a IPs (google.com → 142.250.x.x). Registros: A (IPv4), AAAA (IPv6), MX (correo), NS (servidor DNS), CNAME (alias), TXT (texto), PTR (IP→nombre).
    • 

  • DHCP: reparte IPs automáticamente.
    • 

  • ICMP: mensajes de control; ping lo usa. Muchos firewalls lo bloquean (por eso en Nmap a veces usamos -Pn).
    • 



💡 Truco TTL para adivinar el SOHaz ping y mira el TTL: ≈64 → Linux, ≈128 → Windows, ≈255 → equipos de red (Cisco).

8. Comandos de red esenciales


$ ip a                     # mis interfaces e IPs (Linux)
$ ip route                 # tabla de rutas y gateway
$ ping -c 3 10.0.2.4       # ¿está vivo?
$ sudo arp-scan -l         # equipos en mi red local
$ ss -tulnp                # puertos abiertos en MI máquina
$ nslookup dominio.com     # resolver DNS
$ dig A dominio.com        # DNS más detallado
$ traceroute 8.8.8.8       # por qué routers paso
$ curl -I http://10.0.2.4  # cabeceras HTTP
REM Windows
> ipconfig /all  ·  route print  ·  netstat -ano  ·  arp -a

  4. Un equipo tiene las IPs 10.0.2.15/24 y 172.16.5.10/24. ¿Qué significa para un pentester?
    5. 



Ver soluciones


1. /28 → bloques de 16 (…192, 208…). 200 está en 192–207. Red 10.10.20.192, broadcast 10.10.20.207, hosts .193–.206 (14).


2. 2^(32−22) − 2 = 1024 − 2 = 1022.


3. .224 = 11100000 → 3 bits + 24 = /27. Bloques de 32: 0, 32, 64… → red 192.168.100.32/27.


4. Está conectado a dos redes: es un candidato a pivote para llegar a la red 172.16.5.0/24 (módulo 13).
